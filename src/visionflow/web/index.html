VisionFlow

The pixels decide what happens next.

VisionFlow turns camera, video and image analysis into bounded, reviewable workflows. This example: a wrong-way driver warning for a traffic control room.

Public demo: synthetic traffic · fixed offline model answer · simulated recipients · each camera session ends after two minutes.

  1. 1 · Perceive OpenCV compares every frame with the previous one and finds motion against the lane direction.
  2. 2 · Decide A hit opens a case with an immutable evidence clip. Model and human review the same clip – this is where a car is told apart from a bird or a leaf.
  3. 3 · Act Confirmed cases reach a simulated authority inbox immediately; unanswered cases do so when the deadline expires. A late rejection sends an all-clear.

The same core also checks document photos and watches videos – only the JSON configuration differs. See the “Reusable workflows” tab.
